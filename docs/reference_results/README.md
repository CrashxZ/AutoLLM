# Reference summaries

These are copied derived summaries, not bundled raw episode records. Historical
v4, corrected eight-vehicle follow-up, and local synthetic latency measurements
are distinct datasets and must not be pooled. The follow-up uses previously
examined seeds. Local latency does not include network or physical execution.
Without raw episodes these CSVs are reference values, not independently replayable
evidence. A new run from this release remains a separately identified evaluation.
